# 企业资质文件多文件上传功能改造

## 背景与目标

### 背景
企业在提交资质认证时，需要上传多个资质文件（如营业执照、资质证书、荣誉证书等），原有实现只返回URL字符串，缺少文件元数据管理。

### 目标
改造企业上传资质文件功能，支持：
- 多次上传文件，自动追加到文件列表
- 以JSON数组格式存储文件元数据
- 包含文件名、URL、大小、上传时间等信息

---

## 实现方案

### 数据库设计

`company_profile` 表的 `qualification_files` 字段已经是 JSON 类型，无需修改数据库。

**字段说明**：
- 类型：JSON
- 存储格式：数组，每个元素包含 fileName、fileUrl、fileSize、uploadTime

### 步骤2：修改上传接口

#### 2.1 添加 Fastjson2 导入

在 `UserManagementHttpController.java` 中添加：

```java
import com.alibaba.fastjson2.JSON;
import com.alibaba.fastjson2.JSONArray;
import com.alibaba.fastjson2.JSONObject;
```

#### 2.2 改造 uploadQualificationFile 方法

**核心逻辑**：
1. 上传文件到存储服务
2. 查询企业资料获取现有的 qualificationFiles
3. 解析JSON数组，追加新文件信息
4. 更新企业资料

**实现代码**：
```java
@PostMapping(value = "/company/upload_qualification")
public Response<String> uploadQualificationFile(@RequestParam("file") MultipartFile file, HttpServletRequest request) {
    try {
        String userId = UserContextDynamic.getUserContextDynamic();
        if (StrUtil.isBlank(userId)) {
            throw new AppException(ResponseCode.ILLEGAL_PARAMETER.getCode(), ResponseCode.ILLEGAL_PARAMETER.getInfo());
        }

        String fileUrl = storageService.storeQualificationFile(userId, file);

        CompanyProfileEntity companyProfile = userManagementRepository.queryCompanyProfile(userId);
        if (companyProfile == null) {
            return new Response<>(ResponseCode.ILLEGAL_PARAMETER.getCode(), "企业资料不存在", null);
        }

        JSONArray fileList;
        String existingFiles = companyProfile.getQualificationFiles();
        if (StrUtil.isBlank(existingFiles)) {
            fileList = new JSONArray();
        } else {
            fileList = JSON.parseArray(existingFiles);
        }

        JSONObject fileInfo = new JSONObject();
        fileInfo.put("fileName", file.getOriginalFilename());
        fileInfo.put("fileUrl", fileUrl);
        fileInfo.put("fileSize", file.getSize());
        fileInfo.put("uploadTime", java.time.LocalDateTime.now().toString());
        fileList.add(fileInfo);

        companyProfile.setQualificationFiles(fileList.toJSONString());
        userManagementRepository.updateCompanyProfile(companyProfile);

        log.info("企业上传资质文件成功 userId={}, fileUrl={}, 当前文件数={}", userId, fileUrl, fileList.size());
        return new Response<>(ResponseCode.SUCCESS.getCode(), ResponseCode.SUCCESS.getInfo(), fileUrl);
    } catch (Exception e) {
        log.error("企业上传资质文件失败", e);
        return new Response<>(ResponseCode.UN_ERROR.getCode(), "上传失败：" + e.getMessage(), null);
    }
}
```

## API 接口说明

### 企业上传资质文件

**路径**：`POST /api/v1/user_management/company/upload_qualification`

**请求格式**：`multipart/form-data`

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 资质文件（支持格式：pdf,doc,docx,jpg,jpeg,png,zip,rar，最大10MB） |

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": "/static/qualifications/123456/营业执照.jpg"
}
```

**文件列表格式**：
```json
[
  {
    "fileName": "营业执照.jpg",
    "fileUrl": "/static/qualifications/123456/营业执照.jpg",
    "fileSize": 102400,
    "uploadTime": "2026-03-13T10:00:00"
  },
  {
    "fileName": "资质证书.pdf",
    "fileUrl": "/static/qualifications/123456/资质证书.pdf",
    "fileSize": 204800,
    "uploadTime": "2026-03-13T10:05:00"
  }
]
```

## 使用说明

### 企业上传资质文件

1. 企业登录获取 Token
2. 调用 `POST /api/v1/user_management/company/upload_qualification` 上传第一个文件
3. 继续调用同一接口上传更多文件
4. 每次上传都会自动追加到文件列表中
5. 查询企业资料时，`qualificationFiles` 字段返回完整的文件列表

### 管理员查看资质文件

管理员查询企业资质详情时，可以通过 `qualificationFiles` 字段获取企业提交的所有资质文件列表，包括：
- 文件名
- 访问URL
- 文件大小
- 上传时间

---

## 技术特点

1. **自动追加**：每次上传自动追加到现有文件列表，无需手动管理
2. **元数据完整**：记录文件名、URL、大小、上传时间
3. **向后兼容**：数据库字段无需修改，只是改变了数据格式
4. **统一存储**：复用现有的 StorageService 和文件存储路径
5. **JSON格式**：使用 Fastjson2 处理 JSON 数组
