# 里程碑参考文件上传功能实现

## 背景与目标

### 需求背景
企业在配置项目里程碑时，需要上传参考文件（要求文档、规范文件等）供学生团队查看，帮助团队更好地理解里程碑的具体要求。

### 功能目标
- 支持企业为里程碑上传多个参考文件
- 文件类型：要求文档、规范文件、参考资料等
- 学生团队可以查看和下载这些参考文件

---

## 数据库变更

### 1. 添加字段

在 `project_milestone` 表添加 `reference_files` 字段：

```sql
ALTER TABLE `project_milestone`
ADD COLUMN `reference_files` json NULL COMMENT '企业上传的参考文件列表（要求文档、规范文件等），JSON数组格式'
AFTER `deliverable_url`;
```

### 2. 字段说明

- **字段名**：`reference_files`
- **类型**：JSON
- **可空**：是
- **格式**：JSON数组，存储多个文件对象
- **示例**：
```json
[
  {
    "fileName": "方案提交要求.pdf",
    "fileUrl": "/static/milestones/references/project123/milestone456/方案提交要求.pdf",
    "fileSize": 102400,
    "uploadTime": "2026-03-13T10:00:00"
  },
  {
    "fileName": "开发规范.docx",
    "fileUrl": "/static/milestones/references/project123/milestone456/开发规范.docx",
    "fileSize": 51200,
    "uploadTime": "2026-03-13T10:05:00"
  }
]
```

---

## 实现方案

### 1. 文件存储路径

**路径规则**：`./files/milestones/references/{projectId}/{milestoneId}/{fileName}`

**访问URL**：`/static/milestones/references/{projectId}/{milestoneId}/{fileName}`

### 2. 接口设计

#### 接口1：上传里程碑参考文件

- **路径**：`POST /api/v1/milestone/reference/upload`
- **请求格式**：`multipart/form-data`
- **请求参数**：
  - `milestoneId` (String) - 里程碑ID
  - `file` (File) - 参考文件
- **返回**：文件信息对象
- **权限**：企业用户

#### 接口2：删除里程碑参考文件

- **路径**：`DELETE /api/v1/milestone/reference/delete`
- **请求参数**：
  - `milestoneId` (String) - 里程碑ID
  - `fileUrl` (String) - 文件URL
- **返回**：成功/失败
- **权限**：企业用户
