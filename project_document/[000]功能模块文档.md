## 三、揭榜管理完善模块

**完成时间**：2026-03 阶段

**做了什么**：
- 新增公开揭榜名单查询接口 `GET /api/v1/bid/public/project/{projectId}`。
- 新增学生"我的揭榜"查询接口 `GET /api/v1/bid/student/my-bids`。
- 保留并验证揭榜撤回能力 `POST /api/v1/bid/cancel/{bidId}`。
- 修复跨模块 DTO 依赖缺失与 `int` 类型比较错误。

**权限规则**：
- 学生接口：仅学生角色可访问。
- 企业接口：仅企业角色可访问。
- 公开接口：对外开放，不返回 content/attachmentUrl 等敏感字段。

**相关文档**：`[100]揭榜功能完善阶段实施文档.md`

**相关接口**：见 `[002]API文档.md` → 竞榜管理模块

## 四、team_member 关联表与团队成员能力

**完成时间**：2026-03-09

**做了什么**：
- 新增 `team_member` 表，支持队长/普通成员区分（role: leader / member）。
- 创建团队时同步写入队长 `team_member` 记录。
- 团队详情 `GET /api/v1/team/detail/{teamId}` 和我的团队 `GET /api/v1/team/my` 返回值新增 `members` 字段（含昵称、头像、角色）。
- 学生我的揭榜接口改为 JOIN `team_member`，普通队员也能查到团队揭榜记录。

**注意**：存量团队需手动补一条队长记录：
```sql
INSERT INTO team_member (team_id, user_id, role, join_time)
VALUES ('2020476698205753344', '2018608120762339328', 'leader', NOW());
```

**相关接口**：见 `[002]API文档.md` → 团队管理模块
