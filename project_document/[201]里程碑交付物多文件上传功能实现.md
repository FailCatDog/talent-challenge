# 里程碑交付物多文件上传功能实现

## 背景与目标

### 背景
学生团队在提交里程碑交付物时，往往需要提交多个文件（如方案文档、代码实现、测试报告等），原有的单文件上传方式无法满足需求。

### 目标
实现学生提交里程碑交付物的多文件上传功能，支持：
- 多次上传文件，自动追加到文件列表
- 以JSON数组格式存储文件元数据
- 包含文件名、URL、大小、上传时间等信息

---

## 实现方案

### 数据库设计

在 `project_milestone` 表中新增 `deliverable_files` 字段：

```sql
ALTER TABLE `project_milestone`
ADD COLUMN `deliverable_files` json NULL COMMENT '学生提交的交付物文件列表，JSON数组格式' AFTER `deliverable_url`;
```

**字段说明**：
- 类型：JSON
- 存储格式：数组，每个元素包含 fileName、fileUrl、fileSize、uploadTime
- 与 `deliverable_url` 字段共存，保持向后兼容

7. 返回文件URL

## API 接口说明

### 学生上传里程碑交付物文件

**路径**：`POST /api/v1/milestone/deliverable/files/upload`

**请求格式**：`multipart/form-data`

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| milestoneId | String | 是 | 里程碑ID |
| file | File | 是 | 上传的文件（支持格式：pdf,doc,docx,jpg,jpeg,png,zip,rar，最大10MB） |

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": "/static/milestones/2022959380340805632/milestone123/方案文档.pdf"
}
```

**文件列表格式**：
```json
[
  {
    "fileName": "方案文档.pdf",
    "fileUrl": "/static/milestones/2022959380340805632/milestone123/方案文档.pdf",
    "fileSize": 102400,
    "uploadTime": "2026-03-13T10:00:00"
  },
  {
    "fileName": "代码实现.zip",
    "fileUrl": "/static/milestones/2022959380340805632/milestone123/代码实现.zip",
    "fileSize": 204800,
    "uploadTime": "2026-03-13T10:05:00"
  }
]
```

## 使用说明

### 学生上传交付物文件

1. 学生登录获取 Token
2. 调用 `POST /api/v1/milestone/deliverable/files/upload` 上传第一个文件
3. 继续调用同一接口上传更多文件
4. 每次上传都会自动追加到文件列表中
5. 查询里程碑详情时，`deliverableFiles` 字段返回完整的文件列表

### 企业查看交付物

企业查询里程碑详情时，可以通过 `deliverableFiles` 字段获取学生提交的所有文件列表，包括：
- 文件名
- 访问URL
- 文件大小
- 上传时间

---

## 技术特点

1. **自动追加**：每次上传自动追加到现有文件列表，无需手动管理
2. **元数据完整**：记录文件名、URL、大小、上传时间
3. **向后兼容**：保留原有 `deliverable_url` 字段
4. **统一存储**：复用现有的 StorageService 和文件存储路径
5. **JSON格式**：使用 Fastjson2 处理 JSON 数组
