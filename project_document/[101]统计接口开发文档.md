# [101] 管理员统计接口开发文档

## 背景与目标

管理员后台需要展示平台整体运营数据，包括项目统计、用户统计和项目分类分布。当前已有半成品代码（API层DTO、Domain层VO和Service、Trigger层Controller），但仓储接口缺少方法声明，Infrastructure层缺少实现，Controller存在VO→DTO类型不匹配问题。本次任务是补全整条链路，使统计接口可用。

## 1. 需求分析

### 1.1 项目统计
- 各状态项目数量（draft/pending_review/published/in_progress/completed/cancelled）
- 按时间维度统计（今日新增、本周新增、本月新增）
- 项目总数

### 1.2 用户统计
- 总用户数
- 各类型用户数（学生type=1 / 企业type=2 / 管理员type=3）
- 认证状态统计（certified/pending_review/uncertified/rejected）
- ~~活跃用户数~~（不实现，返回null）

### 1.3 项目分类分布
- 各分类下的项目数量（关联project_category表获取分类名称）

### 1.4 接口信息
- URL: `GET /api/v1/admin/statistics`
- 权限: 管理员
- 返回: 聚合的统计数据

### Step 3: Mapper XML — 编写SQL

**文件: `project_mapper.xml`** 新增SQL：
```sql
<!-- 按状态分组统计 -->
SELECT status, COUNT(*) as count FROM project GROUP BY status

<!-- 按时间统计（参数为起始时间） -->
SELECT COUNT(*) FROM project WHERE create_time >= #{startTime}

<!-- 统计总数 -->
SELECT COUNT(*) FROM project

<!-- 按分类分组统计（LEFT JOIN获取分类名称） -->
SELECT p.category_id, pc.name as category_name, COUNT(*) as project_count
FROM project p
LEFT JOIN project_category pc ON p.category_id = pc.project_category_id
GROUP BY p.category_id, pc.name
```

**文件: `user_mapper.xml`** 新增SQL：
```sql
<!-- 按类型分组统计 -->
SELECT type, COUNT(*) as count FROM user GROUP BY type

<!-- 统计总数 -->
SELECT COUNT(*) FROM user
```

**文件: `company_profile_mapper.xml`** 新增SQL：
```sql
<!-- 按认证状态分组统计 -->
SELECT certification_status, COUNT(*) as count
FROM company_profile GROUP BY certification_status
```

### Step 5: Trigger层 — Controller VO→DTO转换

**文件: `StatisticsHttpController.java`**

当前问题：`StatisticsResponse` 构造函数期望 DTO 类型，但 Service 返回的是 VO 类型。

修改方案：在 Controller 中做 VO→DTO 手动转换：
```java
// ProjectStatisticsVO → ProjectStatisticsDTO
ProjectStatisticsVO projectVO = projectStatisticsService.getProjectStatistics();
ProjectStatisticsDTO projectDTO = ProjectStatisticsDTO.builder()
        .statusCount(projectVO.getStatusCount())
        .todayCount(projectVO.getTodayCount())
        .weekCount(projectVO.getWeekCount())
        .monthCount(projectVO.getMonthCount())
        .totalCount(projectVO.getTotalCount())
        .build();

// UserStatisticsVO → UserStatisticsDTO
UserStatisticsVO userVO = userStatisticsService.getUserStatistics();
UserStatisticsDTO userDTO = UserStatisticsDTO.builder()
        .totalCount(userVO.getTotalCount())
        .studentCount(userVO.getStudentCount())
        .companyCount(userVO.getCompanyCount())
        .adminCount(userVO.getAdminCount())
        .activeCount(userVO.getActiveCount())
        .certificationStatusCount(userVO.getCertificationStatusCount())
        .build();

// List<CategoryDistributionVO> → List<CategoryDistributionDTO>
List<CategoryDistributionDTO> categoryDTOs = categoryDistributionService
        .getCategoryDistribution().stream()
        .map(vo -> CategoryDistributionDTO.builder()
                .categoryId(vo.getCategoryId())
                .categoryName(vo.getCategoryName())
                .projectCount(vo.getProjectCount())
                .build())
        .collect(Collectors.toList());
```

## 4. 详细设计

### 4.1 涉及的数据库表

| 表名 | 用途 | 关键字段 |
|---|---|---|
| `project` | 项目统计 | `status`, `create_time`, `category_id` |
| `project_category` | 分类名称 | `project_category_id`, `name` |
| `user` | 用户统计 | `type`（1=学生,2=企业,3=管理员） |
| `company_profile` | 认证统计 | `certification_status` |

### 4.2 时间维度计算规则
- 今日：`create_time >= 当天00:00:00`
- 本周：`create_time >= 本周一00:00:00`
- 本月：`create_time >= 本月1日00:00:00`
- 时间计算在 Java 层使用 `LocalDate` 完成，传字符串给 SQL
